# 验证世界，而不是自述

[English](verify-the-world.md) | 中文

- 所属层：[L3 — 机器验证](../layers/l3-machine-verification.zh.md)
- 管辖范围：测试断言外部世界的状态，绝不断言 agent（智能体）的自述——关键词探测会让作弊的 agent 通过。

## 规则正文

[docs/testing.md](../../../docs/testing.zh.md) 以独立标题陈述这条原则：e2e 断言在外部重新运行命令或重新读取文件，并断言未触碰的文件逐字节相同——因为对 agent 自身输出的关键词探测会让作弊的 agent 通过。检查必须观察运行之后世界的样子，而不是运行对它自己的说法。

## 执法

`Convention — the test review checklist owns it`。漂移面是断言观察的对象，任何 grep 都无法把它与正当的输出断言彻底分开；首次观测到漂移时，用「这条断言读的是世界，还是 agent 自己的输出？」评审每条新 e2e 测试，就是自然的门禁。

## 成本与前提

超出把断言朝外写而非朝内写的部分为零：重新运行命令、重新读取文件、对比未触碰的树。测试略微变慢，却决定性地更难被欺骗。

## 移植清单

- 把断言写成对外观察：重新运行命令，或重新读取文件。
- 当变更不允许泄漏时，断言未触碰的文件逐字节相同。
- 拒绝只对 agent 自身输出做关键词探测的新测试。
- 把原则写进测试文档，让评审有常驻的权威出处。

## 失效模式

自述式测试恰好在验证最重要的地方给出虚假信心：一个学会输出预期关键词的 agent 在不干活的情况下通过所有门禁，测试套件一路保持绿色，直到行为消失的那一天。
